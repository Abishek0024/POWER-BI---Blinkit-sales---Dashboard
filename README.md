# POWER-BI---Blinkit-sales---Dashboard
# 🛒 Blinkit Sales Performance Dashboard  

---

## 1. Project Title / Headline  
**Blinkit Sales Performance Insights Dashboard**  
An interactive Power BI dashboard analyzing sales, outlet types, fat content distribution, and item performance for Blinkit (India’s last-minute app).  

---

## 2. Short Description / Purpose  
The Blinkit Dashboard provides a comprehensive overview of **sales performance across different outlet types, sizes, and locations**.  
It helps in understanding **customer preferences, sales trends, and product category performance**.  

This project can be used by **retail analysts, managers, and stakeholders** to make data-driven decisions on outlet management and product strategies.  

---

## 3. Tech Stack  
- 📊 **Power BI Desktop** – Dashboard creation and visualization.  
- 🔄 **Power Query** – Data cleaning & transformation.  
- 🧮 **DAX** – Used for measures (Total Sales, Avg Sales, Ratings, Item Visibility).  
- 🗂 **Excel/CSV** – Source dataset.  

---

## 4. Dataset  
- **Total Sales:** $1.20M  
- **Total Items:** 8,523  
- **Avg Sales per Transaction:** $141  
- **Avg Rating:** 3.9  

Columns include: Item Type, Fat Content, Outlet Size, Outlet Location, Outlet Type, Sales, Ratings, and Visibility.  

---

## 5. Dashboard Features  
✅ **KPI Cards** → Total Sales, Avg Sales, Avg Rating, No. of Items  
✅ **Line Chart** → Sales trend by Outlet Establishment Year  
✅ **Donut Chart** → Sales by Outlet Size  
✅ **Bar Chart** → Sales by Location Tier (Tier 1, Tier 2, Tier 3)  
✅ **Bar Chart** → Sales by Item Type (Fruits, Snacks, Household, Dairy, etc.)  
✅ **Comparison** → Low Fat vs Regular products  
✅ **Outlet Type Table** → Sales, No. of Items, Avg Sales, Avg Rating, Item Visibility  

---

## 6. Key Insights  
- 🥇 **Supermarket Type 1** generated the highest sales ($787.55K).  
- 📱 **Tier 3 outlets** had the largest sales ($472.13K).  
- 🥛 Regular fat items contributed **$776.32K**, higher than low-fat ($425.36K).  
- 🏪 **Small and medium outlets** contributed more sales compared to large outlets.  
- 📈 Sales peaked in **2018 ($205K)** before declining slightly.
